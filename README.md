

## 🌟 项目简介

这是一个基于 **Node.js + Express + Vue3 + uni-app + MySQL** 构建的农商信息交流平台。

### 🧩 功能模块一览

- **用户端**：登录注册 / 店铺信息浏览 / 农产品信息 / 加入购物车 / 下单与订单查询 / 收货地址 / 论坛交流 / 用户反馈 / 公告资讯 / 个人中心
- **农民端**：登录注册 / 农产品信息发布与管理 / 店铺信息管理 / 订单处理
- **管理端**：用户管理 / 农民管理 / 产品分类管理 / 农产品信息管理 / 店铺信息管理 / 用户反馈管理 / 商品订单 / 论坛交流管理 / 公告资讯管理 / 轮播图管理
